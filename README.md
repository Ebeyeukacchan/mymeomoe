# QUẢN LÝ GIÁ CÂY CẢNH

## Giới thiệu

Dự án quản lý giá cây cảnh giúp người dùng theo dõi và quản lý thông tin các loại cây cảnh.

## Chức năng

- Thêm cây cảnh
- Hiển thị danh sách cây cảnh
- Cập nhật thông tin cây
- Xóa cây cảnh
- Tìm kiếm cây cảnh
- Cập nhật giá cây
- Sắp xếp cây theo giá
- Thống kê giá cây

## Thông tin cây cảnh

Mỗi cây cảnh gồm các thông tin:

- Mã cây
- Tên cây
- Loại cây
- Giá bán
- Số lượng
- Mô tả
